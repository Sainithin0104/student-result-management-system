# 🎓 Student Result Management System

A Python project that helps manage student records efficiently.

## Features
- ➕ Add Student
- 📊 Calculate Total and Percentage
- 🏅 Generate Grade and Rank
- ✅ Pass/Fail Result
- 💬 Remarks Generation
- 🔍 Search Student by Roll Number
- 📈 Class Report
- 💾 File Handling
- 🏆 Find Class Topper

## Technologies Used
- Python
- File Handling
- Dictionaries
- Lists
- Loops
- Conditional Statements
